SDFGI RW-storage shadow-split repro — Round 46

Not Godot, but models real driver code exactly: without the 'readonly-and-readwrite-storage-textures' feature (confirmed absent on this session's real-GPU adapter), the WebGPU driver splits every read_write storage texture into a write-only storage side plus a separate "shadow" sampled texture kept in sync via an explicit copyTextureToTexture issued right before each bind. This repro tests whether that copy-based refresh breaks the same telescoping accumulator that works correctly through direct read_write storage access (race_repro.js/Round 40).
